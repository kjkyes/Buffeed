# 服务与数据目录

## 服务清单

| 服务 | 默认端口 | 数据/配置来源 | 是否由 desktop 打包 |
| --- | --- | --- | --- |
| Agent API | 8765 | 统一用户目录 `BUFFEED_HOME/state`；workspace | backend 携带 canonical `apps/agent-runtime` |
| RAG Gateway | 8001 | `apps/rag/rag_api.py`、`apps/rag/config`；默认数据根仍为 `data/rag` | 否 |
| LightRAG | 9621 | Compose volume `lightrag_working` | 否 |
| Docling | 5001 | Docker image | 否 |
| RAG worker | 无对外端口 | Compose volume 和数据库 | 否 |

## 不纳入源码迁移的数据

- `data/rag/inputs`
- `data/rag/secrets`
- `data/rag/rag_storage`
- Compose named volumes
- `BUFFEED_HOME/state/desktop.db`（打包版默认位于当前用户主目录下的 `.buffeed\state`，可用 `BUFFEED_HOME` 或 `DESKTOP_STATE_DIR` 覆盖）
- `BUFFEED_HOME/workspaces/<workspace-hash>/`：CLI transcript、memory、task、mailbox 和定时任务状态
- 日志、缓存、模型权重和构建输出

## 配置原则

- 生产解析使用 Docling。
- `LIGHTRAG_BASE_URL` 由 Gateway 配置，renderer 不直接读取。
- RAG 的 `search_ready` 和 `graph_ready` 分开报告。
- 迁移目录时优先迁移配置模板和启动说明，最后再迁移数据路径。

## 视频对象存储与缓存

根目录 `.env` 可以配置腾讯云 COS：`COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_REGION`、`COS_BUCKET` 为必备字段，`COS_SESSION_TOKEN`、`COS_OBJECT_PREFIX` 和 `COS_URL_EXPIRE_SECONDS` 为可选字段。占位值不会启用上传；替换为真实凭据后，短视频超出本地直传大小限制时才会尝试上传，失败会回退到关键帧分析。COS 上传使用原视频，不会删除 Electron 的预览缓存或工作区解析帧。

视频分析缓存和 Chromium 预览缓存独立清理：分析缓存位于对应 workspace 的 `BUFFEED_HOME/workspaces/<workspace-hash>/video-cache/analysis/`，默认保留 30 天/最多 1 GiB，在视频处理前清理；预览缓存默认保留 14 天/最多 1 GiB，在 desktop 启动时清理。可分别通过 `DESKTOP_VIDEO_ANALYSIS_CACHE_MAX_AGE_DAYS`、`DESKTOP_VIDEO_ANALYSIS_CACHE_MAX_BYTES`、`DESKTOP_VIDEO_PREVIEW_CACHE_MAX_AGE_DAYS` 和 `DESKTOP_VIDEO_PREVIEW_CACHE_MAX_BYTES` 调整。

## 源码根与数据根

`apps/rag/source_layout.py` 是 RAG 源码/数据边界的唯一解析入口：源码固定来自 `apps/rag`，`RAG_DATA_ROOT` 默认指向 `data/rag`。`data/rag`。

Compose 的 `RAG_INGEST_HOST_DIR` 是宿主机目录，Gateway 容器内对应 `/srv/rag/ingest`；Electron 的 `RAG_INGEST_MODE` 默认按 host 处理，直接运行 Gateway 时可使用绝对宿主机路径；Compose 场景请显式设置 `RAG_INGEST_MODE=container`，再使用 `RAG_INGEST_GATEWAY_DIR`（默认 `/srv/rag/ingest`）。
