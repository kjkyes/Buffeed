# 产品主循环

## 定位

Buffeed 是一个面向本地开发与知识工作的 Agent 工作台，采用 Harness 范式统一编排模型、工具、上下文与执行流程；支持可观测的 Agent Team，实时展示成员、任务、事件和依赖关系；支持文本、图片、文档、音视频等多模态输入；兼容 MCP、Skills 等多种插件机制，并内置浏览器、终端、文件预览、代码审查等插件；同时提供 RAG 知识库接入、文档解析、混合检索和任务协同能力。

## 当前主循环

```text
用户目标 -> 创建 session -> 发起 turn -> 模型请求工具
    -> 审批/执行/事件回放 -> turn 完成或取消 -> 用户查看产物
```
