# 文档索引

这是项目文档的唯一导航入口。先看本页，再进入对应领域正文；不要把旧的 `.doc` 文件或运行产物当作当前架构事实。


## 推荐阅读顺序

1. 产品主循环
2. 项目结构和运行时地图
3. 事件契约
4. 服务与数据目录

## 按任务路由

| 任务 | 权威入口 |
| --- | --- |
| 修改 Agent API、SQLite journal、SSE 或 Team 回放 | `apps/agent-runtime/desktop_api.py`、`runtime_store.py`、`team_events.py` |
| 修改 Buffeed Team 生命周期 | `apps/agent-runtime/Buffeed_core.py` |
| 修改 RAG REST/MCP、worker、registry 或配置加载 | `apps/rag`；源码/数据根规则见 `apps/rag/source_layout.py` |
| 修改 Electron UI、状态 hook 或 Team 画布 | `apps/desktop/src` |
| 修改 wire 类型 | `packages/contracts` |
| 安装或更新 Agent runtime 依赖 | `apps/agent-runtime/pyproject.toml`、`apps/agent-runtime/uv.lock` |
| 安装或更新 RAG 依赖 | `apps/rag/pyproject.toml`、`apps/rag/uv.lock`；Compose 入口另看 `apps/rag/requirements.txt` |

## 现有材料
